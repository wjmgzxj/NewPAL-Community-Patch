# 安装与还原

仅供Steam正版玩家；先备份自己的游戏和存档。当前候选需最新EXE与125张清单内PNG配套，不是只有一个EXE。

## 无需Python：手动安装

1. 保存并正常退出游戏，关闭传送器。
2. Steam中右键游戏→管理→浏览本地文件。
3. 备份原EXE；按包内资源清单备份已有同名PNG，并记下哪些是新增文件。
4. 将当前补丁包内EXE与Resource合并复制到游戏目录，替换同名文件。不删除原Resource，不形成Resource/Resource，不复制任何人的存档和设置。
5. 通过Steam启动；需要手柄时在Steam启动流程中保持输入配置。

还原时退出游戏，放回自己的原EXE和原有同名图片；只删除清单中原先没有的新增PNG。不要删除不相关的原游戏资源。地图探索附属记录可能不被旧补丁识别，回退后可能重新积累地图探索，人物进度仍以原生存档为准。

## 开发者：自行重建安装文件

按[构建与验证](构建与验证.md)，提供自己的精确支持原版EXE，在独立空目录重建当前EXE与119图，再按上面的步骤安装。重建工具不是自动安装器，不写正在运行的游戏。

地图M/Back切换、Esc/B关闭；Start是主菜单。不遇敌设置控制战后10秒保护，不是全程无限不遇敌。传送器的无限不遇敌只用于测试，见工具说明。
