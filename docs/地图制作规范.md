# 地图制作规范

目标是让每条路线、分支、死路、楼梯和出入口正确对应，人物处于正确路段，不追求原画每个像素复刻。环境可以是洞、树林、水面、建筑，不把全部地图画成山洞。

1. 先检查两套攻略的分段和既有批量生图。单图准确可用就直接复用或轻抠，清理无关底色/旧UI；不因尚未核查就判定必须重做。只有密集多片或明确路线畸变才作局部修复/碎片拼合。
2. 建立场景、剧情阶段、资源、层和原生出口表，按边界/碰撞及两站参考核线。攻略细线可能代表跨场景连接，交叉不自动成为路口；看不清时核原生出口，不凭视觉猜通。
3. 复杂地图先拼经过验证的独立透明块，保持局部比例，合理聚拢。过大且关联较远的拆成前/后等页，跨页双方标相同连接编号和目的地。保留梦境与再入隔离。
4. 统一羊皮纸底与梦境文字/图例基准。640×480逻辑画布，标题、右图例和页脚固定留安全区；副标题写“线路图”，不写“预览”。文字采用清晰原件，避免截图重复放大。
5. 主体道路为视觉重点，非路线的水/背景可沿形状柔和退到纸面，不能用内部矩形边框掩盖贴图硬边。不贴不同纸色的矩形补丁。人物使用400px清晰原件一次缩到25px，不用模糊预览头像。
6. 先短且清楚地布线，再放标签。避开大绕行、重合线和文字，连接端点精确；用克制的颜色/节奏/断口区分交叠，不添加不存在的实路。前3、后17的用户指定折线路径是保留约束。
7. 地形、固定UI、可探索名称、人物、迷雾分别处理。片区名实际进入后才整块显示，离开保留、随存档恢复，早档回滚；共享逻辑名不解开其他层地形。
8. 输出完整、局部和游戏尺寸预览，先看再接入。布局移动需同步世界→页变换、人物、端口、alpha及旧探索迁移。保留世界端口与碰撞原数据，不为适应错误图形扭曲它们。
9. 离线核对之后做实际人物点、经过连接、层切换、探索及保存/读档；用户操作游戏，开发端只请求必要样例。不把瞬移成功当剧情阶段正确，不把离线检查当实机验收。

已安装PNG在Resource，当前图集、名称分组和代码符号在对应候选元数据中。清晰母版与后续批量美术源须有明确来源及任务状态。原生碰撞/地图提取研究另行生成，不将研究原件误作项目自制美术。

每次留下具体疑问、证据、解决方法及仍有限制；同一输入和已通过范围不反复研究。流程可改进，但先记录为什么，避免下一人重走废弃路线。

## 当前人工参与流程

十里坡已采用用户修图/排布、程序配准及实机检查的协作方式。具体交付和验收顺序见[人工参与制图流程](人工参与制图流程.md)；旧资料中的强制高清PSD或所有地图逐块重做，不是当前要求。
