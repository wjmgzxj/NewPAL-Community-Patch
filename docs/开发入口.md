# 接手开发

按README→baseline.json→本页→相关模块的顺序读取，不需要复读所有历史试验。源码依赖图在source-modules.json；有效研究源码在`补丁工作仓库/脚本`，必要符号/图集元数据在对应`候选版本`。这些JSON是当前库函数的输入或依据，不是历代EXE下载目录。

先用自己的原版重建当前候选并核对哈希，建立只读基线。做修改时另存候选，记录输入哈希、目标行为、改动文件和检查范围。不要在用户运行游戏时修改磁盘EXE或密集注入输入监测。

现有源码继承了多轮模块依赖，部分main函数仍用于当时基线，不能直接运行。当前提供冻结差分重建和地图运行代码核对；将所有功能统一成无历史路径的源码构建入口仍是明确待办，不冒充已经完成。

攻略顺序第04类十里坡已接入；继续后续地图前先检查已有批量生图和攻略分段；单图不是默认拼接任务。其余未接入迷宫按顺序逐组开发。动态剧情点和出入口方向指引另有事件状态研究，不能用静态攻略点冒充实时功能。

接手练习：修改一个功能参数并说明对应代码区；调整一个地图片区并同步显示变换/端口/alpha/探索兼容；使用固定基线生成可审查回流。任何练习遇到缺文件、私有路径或无法复现的假设，请记录为待解决事项，不自行猜测已通过。

本轮新增：tools/build_updated_from_source.py可从原版＋冻结0.3.0基线编译恢复/提示/炼蛊三项；详见构建与验证.md。函数与复用教训见[炼蛊与战后机制](炼蛊与战后机制.md)，当前实测范围见[状态](当前状态.json)与[工作记录摘要](本轮工作记录.md)。
