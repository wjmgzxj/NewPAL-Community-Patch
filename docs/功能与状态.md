# 功能与状态

唯一当前基线见根目录baseline.json。下面是本候选最终行为，不通过旧源码文件名猜测采用了哪种历史方案。

- 战后10秒不遇敌保护与37.5%亮度的在队角色闪光，Boss和小怪不闪；十里香原生60秒效果期间停用新增保护和闪光。系统设置可开关，重启保留。
- 手柄快走起步、A/B与通用摇杆输入修正；按住鼠标八方向行走、窗口边缘与跨场景续走、普通指针显示和远距离抓手提示。抓手提示不扩大真实交互距离；单击寻路和尖角自动贴边未做。
- 进入战斗提速，画面/UI可提前开始，保留普通/蛇怪遇敌叫声与随后接上的音乐。
- 地图小怪减速和较小追击范围，原生剧情飞行、追击过场及乘莲速度不被全局拖慢。普通AI判定与脚本运动区分，不能恢复旧错误偏移或全局速度限制。
- HP/MP成长上限9999及四位数字布局；撤销独立战后6%，原生恢复量q=trunc(上限/3)，新量q+trunc(q/6)，原条件、复活、MP累加与上限裁剪保留。该原生分支处理HP0队员，存活者不额外6%；随机成长保持原概率、累计门槛减半。
- 合体攻击沿用原招式目标、动画和差异公式，追加随成长的加成；保留原扣HP，不额外扣MP；不采用全体化或普攻保底的废弃方案。
- 普通群攻死亡表现同时启动、重复声音合并，奖励仍按原规则结算；特殊剧情模板回退。蛇怪左上坏帧修正在EXE帧选择处。
- 地图覆盖梦境、再入罗刹前/后、荷花池、十里坡（17/18/817）。沿真实移动逐步揭雾，半径60px；人物为清晰金色小人。荷花运输中途采样，不能把瞬移两端插值成探索路线。
- 拼图标题未进入隐藏，进入后整块显示，保存/读档尊重对应进度；名称可共享逻辑组，但楼层地形和探索不得串层。

当前新增标题逻辑有17个再入场景、16种梦境进入组合及存档回滚/缺图安全的离线检查，最终实机反馈待补。地图风格/定位/迁移等已有离线证据，不能据此宣称全部地图或所有硬件实机通过。实时剧情目标和金银出入口方向指引尚未全面完成，其他迷宫仍待接入。

## v0.3.1新增与验收

炼蛊皿支持最高99批量，净容量/材料上限、默认01、名牌预览与实际产量提示，保留原生材料框/背景/合拢；用户确认首次选料、指针和合拢正常，其他批量细节另有有限反馈与54类离线检查，不代表所有配方/硬件遍历。战后两类提示可空格/回车/A/B/左键提前结束，离线检查通过，独立实机反馈待补。原生恢复v2有10,000整数及80三人结算案例，仍未单独获得实机反馈。

v0.3.1含119张运行PNG；当前版含125张。不会替玩家解锁炼蛊皿，不附测试存档；通过正常剧情取得道具后使用。旧可选传送器尚未登记本版EXE基线，不保证连接。详见[炼蛊与战后机制](炼蛊与战后机制.md)。

## v0.3.2新增与当前边界

- 十里坡接入定位、揭雾和随存档的探索记录，场景17/18/817各自保存探索，地图可共享美术；不代表所有山顶/庙宇等关联场景已经覆盖。用户确认地图落地。
- 战后10秒保护允许主动点击敌人进入原生交互、开宝箱，仍阻挡被动碰撞遇敌。十里香与设置开关的既有机制保留。
- 统一结算消息链支持新按下的左键、空格、回车、小键盘回车、手柄A/B跳过当前提示，覆盖经验、道具、升级、属性、学技能、逃跑等，奖励不跳结算。用户确认战后信息跳过正常。
- 新增人工参与制图流程：用户修图/排布，程序依稳定地标配准并维护定位、迷雾、出口；不要求用户填写坐标表。
- 启动双鼠标/等待光标、战后弹窗遮挡鼠标仍待修；不包含已被否定的置顶v6/v7候选。原生恢复及旧片区标题的独立完整实机验收仍不因此变为通过。

公开传送器独立版本未核对本版新增链路，不保证连接；本轮复用固定的独立工具ZIP一并上传，未重建或修改工具。机制及复用教训见[保护期与结算机制](保护期与结算机制.md)。
