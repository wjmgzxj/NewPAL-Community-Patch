# 协作开发包

本包是当前发布提交的公开源码快照，包含研究索引、地图制作规范、人工参与制图流程、构建入口、运行PNG和回流规则；与GitHub同一版本。普通玩家不需要它。

先读README.md、AGENTS.md、baseline.json、docs/开发入口.md，再按docs/构建与验证.md提供自己的正版原版EXE，重建当前基线。源码包不含游戏本体、测试存档、私人备份或开发环境。工具按docs/工具说明.md另行下载。

修复在单独候选目录开展，记录输入/输出哈希、修改源码、复现步骤、验证范围和用户反馈。只提交改动及必要资料，不回传整个游戏、账号、密钥或未经清理日志。按CONTRIBUTING.md供维护者审阅整合，不覆盖现行正式文件。
