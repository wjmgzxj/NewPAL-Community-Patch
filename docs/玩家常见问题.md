# 玩家常见问题与反馈说明

本页面向安装 **v0.3.1-preview** 的普通玩家。完整功能范围以[功能与状态](功能与状态.md)、游戏适配校验以[baseline.json](../baseline.json)为准。

## 我应该下载哪个文件？

从[发布页](https://github.com/lihang801290-design/NewPAL-Community-Patch/releases/tag/v0.3.1-preview)下载 **NewPAL_Patch_v0.3.1-preview.zip** 即可。

`NewPAL_MapTester` 是地图测试用的独立传送器；`NewPAL_MapArtSources` 是地图美术候选素材，**都不是普通玩家必装文件**。不要点击仓库首页绿色 Code 按钮的 Download ZIP 来代替补丁安装包。

## 必须拥有游戏本体吗？

是。本项目只面向受支持的 Steam 正版《新仙剑奇侠传》。不含游戏本体，不能独立运行；不保证其他渠道或不同 EXE 版本兼容。

## 怎么安装？是否要安装 Python？

普通玩家**不需要 Python**。退出游戏，先备份原游戏 EXE、会被覆盖的同名 PNG 和自己的存档，然后将补丁包内 **EXE 与 Resource 中配套的 119 张 PNG** 一起按目录结构复制到游戏目录。切勿删掉整个原版 Resource 文件夹，也不要形成多一层 Resource/Resource。细节见[安装与还原](安装与还原.md)。

## 会修改存档吗？如何卸载？

建议安装前另行备份存档。还原时退出游戏，恢复原 EXE 和被覆盖的同名图片；只删除原先不存在、由补丁新增的 PNG。地图探索附属记录在回退后可能不被旧版识别，探索进度可能需要重新积累；人物游戏进度仍以原生存档为准。详见[安装与还原](安装与还原.md)。

## 地图已经覆盖全部迷宫了吗？

没有。目前仅覆盖 **梦境罗刹洞、再入罗刹洞前／后、荷花池**。地图 `M` / 手柄 Back 打开或关闭，`Esc` / `B` 关闭，`Start` 仍打开原游戏主菜单。其他迷宫继续开发。

## 这版已经完整测试了吗？

没有。部分功能已做离线验证；最新的片区名按实际进入显隐规则仍需要最终实机反馈。全部剧情、全部迷宫和全部手柄设备尚未全面通过实机验证。下载者应按**预览版**的标准评估风险并留好还原途径。

## 看见战后保护，是不是全程不遇敌？

不是。正式玩家补丁是战后 10 秒保护，涉及十里香原有效果联动和系统设置开关。地图测试传送器可能提供的测试用不遇敌模式，不是普通玩家补丁的持续效果。

## 为什么要替换 EXE？安全吗？

目前补丁包含修改后的 EXE，并需要对应的资源文件配套。发行页提供 SHA256 校验值，便于检查文件是否与发布附件一致；**校验值本身不能保证软件没有缺陷或安全风险**。请仅从本项目官方 GitHub Release 获取附件，备份后测试。与游戏发行方无官方关联。

## 遇到问题，怎么反馈最有帮助？

请使用[问题反馈入口](https://github.com/lihang801290-design/NewPAL-Community-Patch/issues/new/choose)，写明：

- 游戏来源及版本（例如 Steam）、补丁版本；
- 具体地图或剧情阶段、使用键鼠还是手柄；
- 怎样操作会复现；**预期结果**与**实际结果**；
- 是否可以重复出现；必要时上传脱敏截图或简短录屏。

**不要上传访问密钥、账号信息、私人配置、未经检查的完整日志或完整私人存档。** 如果游戏无法启动，先按还原步骤恢复原文件；不要在不确定版本的情况下反复覆盖 EXE。

## 能否参与地图制作或源码开发？

可以。开发者请先阅读[开发入口](开发入口.md)、[协作规则](../CONTRIBUTING.md)及[地图制作规范](地图制作规范.md)，严格遵守当前基线与许可。项目内容供非商业目的免费修改和分发；第三方内容的权利不由本项目授予。
