# 人工参与制图与程序配准

本流程以十里坡已落地的合作方式为例。美术修图、程序配准和实机验收分别交付，避免反复生图和坐标猜测。

1. 先核对两套攻略分段、原生场景/资源身份、道路边界与出口。`(格值 & 0x60800000)==0`形成的包络配合碰撞、落点及出口补缺；不以阴影、明暗、遮挡否定道路，多层投影交叉不自动相连。
2. 单图优先复用现有可用美术，必要时轻抠。密集多片（尤其超过五片）按拆分攻略分组，保持稳定片区ID；过大拆页，跨页出口成对标注。无需手工重做全部地图。
3. 程序方提供原图/道路参考、固定纸面与标题/图例/页脚安全区。用户修透明PNG、排布和补边，保持各块比例、路径、楼梯/洞口等稳定地标；可附图层源文件，但不强制PSD，也不要求填写坐标表。
4. 美术沿梦境版的纸面、字号、标题位置、图例和提示规范；山洞/室外各用适当材质。地图周边自然消隐，不叠加硬内框，不保留矩形拼贴底。清晰原件只做必要缩放，不把低清预览当源素材。
5. 程序方用至少数个分散的对应地标拟合等比变换，检查误差及留出地标；整张图边框对齐不等于路对齐。若图内相对关系改变，分块配准或修图，不能强扭路线。整块移动/缩放需同步定位、端口、alpha、迷雾和旧探索兼容。
6. 给出完整页和游戏尺寸预览，用户修改排布后再接入。实机分别检查人物点、道路/层转换、跨页、走动/运输揭雾及保存回读；成功传送不替代这些检查。通过后固定PNG、变换、资源清单、源码和状态记录。

十里坡：以四处石阶中心校准，原生图到美术图等比尺度约0.640801，平移约(96.17,62.57)，最大地标残差2.09美术像素；最终页变换见公开atlas.json。场景17、18、817共享美术，各自记录探索。该数值是本例结果，不能套到其他地图。

片区小标题只在实际进入后显示；人物图标保持高清。资源、美术和探索用各自ID，梦境与再入不可互绑。后续每张地图先预览，再由用户反馈后落地。新方法一旦证实更简洁，记录原因并替换旧步骤，保留必要失败教训，不继续执行已放弃的方案。
