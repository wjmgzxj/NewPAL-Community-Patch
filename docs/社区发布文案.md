## 社区介绍（推荐）

**标题：** 《新仙剑奇侠传》Steam 版社区优化补丁 v0.3.1-preview：改善战斗等待、移动操作，新增部分迷宫探索地图

《新仙剑奇侠传》Steam 版有些老问题会明显影响重温游戏的体验。这个免费、非官方的社区补丁尝试逐步解决运行卡死、操作不顺、普通地图怪物追得太紧和战斗演出等待过长等问题，并增加了一个尚在制作中的迷宫探索地图系统。

目前公开的 v0.3.1-preview 主要包含：

- **运行和操作：** 针对维护者 Windows 11 环境里遇到的频繁卡死／闪退做了修复；改善手柄起步、A／B 按键误连发、键鼠移动卡顿和鼠标长按跨场景移动。其他系统与硬件仍需实机反馈。
- **探索和遇敌：** 普通小怪追击速度及范围下调，战斗胜利或逃跑后提供可开关的 10 秒不遇敌保护，与十里香原有机制协调。
- **战斗节奏：** 调整进入战斗时画面、音效和音乐的衔接；多目标被群攻消灭后可同时开始死亡演出，并修复部分异常帧。**主要改变等待与体感，不改变原游戏战斗画风**。
- **养成：** HP／MP 上限扩展至 9999、原生战后恢复量增加其六分之一，保留原生恢复／复活条件、属性成长门槛调整以及合体攻击伤害加成。
- **探索地图测试版：** 已支持梦境罗刹洞、再入罗刹洞前／后和仙灵岛荷花池，按 `M`／手柄 Back 打开地图，沿实际走过的路线逐步揭开迷雾、保存探索进度；其他迷宫继续开发。

**下载：** https://github.com/lihang801290-design/NewPAL-Community-Patch/releases/tag/v0.3.1-preview

普通玩家只需下载 `NewPAL_Patch_v0.3.1-preview.zip`，安装前请备份游戏 EXE、受影响的 Resource 文件和存档，按仓库安装指南操作。只适用于受支持的 Steam 正版基线，不适用于旧 CD 版。本项目不提供游戏本体。

另外有可选的地图传送测试工具及开发用地图美术候选素材，**不是普通玩家必装组件**。当前版本仍在测试，欢迎反馈不同 Windows 系统、手柄和具体剧情场景下可复现的问题。
