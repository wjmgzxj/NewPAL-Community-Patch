# 传送器接口兼容与重建

工具版本：map-tester-v0.3.1-preview，独立于玩家补丁v0.3.1。取消完整游戏EXE的SHA1白名单；保留格数据完整性、发布下载和构建输入的校验，这些用途不同。

`map_test_compat_v2.py`在打开进程前选择显式审核的接口规则，随后在使用/安装测试桥前核对运行时对应字节。核对范围包括PE架构/状态区读写布局、时钟IAT、传送/场景装载/存档入口、相关桥及其固定表。原版/v5的六处临时桥入口由原有attach事务继续原子核对，允许同一进程内重新连接已有的相同休眠桥；项目内置NMT1桥不支持映像重定位。

无关炼蛊等功能变化不会仅因整体EXE身份改变被拒绝；接口区域变化仍须研究并明确增加规则，不要盲目重新采样未知版本来消除错误。已检查窗口不是整个下游代码的形式化证明，不保证任意第三方修改版兼容。原版/v5临时RAM桥代码、普通不遇敌、存档守卫、三秒租约及输入机制不改。

离线验证覆盖原版、正式v5、项目v0.3.0及公开v0.3.1，48个相关区域破坏案例拒绝、5组模拟运行时检查通过；隐藏独立检查加载513场景、426格数据、475预览并识别公开v0.3.1。新识别版真实连接待用户反馈，不能将既有瞬移反馈扩展成所有场景/硬件验收。摘要见[验证数据](map-tool-validation.json)。

## 复用与构建

普通使用下载独立EXE即可，无需Python。开发者使用Windows x64、Python 3.10、PyInstaller、pefile；新构建不从原始大图重复缩放。先下载本标签工具并解压，用已核对的独立EXE提供其内嵌的固定目录/格数据/预览：

```powershell
python tools/build_map_tester.py --data-from-tool "下载目录/新仙剑地图传送器.exe" --output "独立空输出目录"
```

构建器核对`tool-baseline.json`后只解析数据，不运行所给EXE；接口规则必须与仓库`tool-data/传送接口兼容规则.json`一致。依赖已有数据包，不能宣称仅源码即可重新提取原生地图。PyInstaller/环境变化可能导致最终字节哈希不同，实际逻辑和数据还须检查。

```powershell
python tools/verify_map_tool_interfaces.py --exe "自己的游戏/NewPAL_Release.exe"
```

该命令只读磁盘并模拟受保护区域破坏，不连接游戏。重建的EXE可加`--self-check --check-exe "自己的游戏/NewPAL_Release.exe" --report "检查报告.json"`做隐藏资源与接口检查，仍不连接游戏。报告、配置、日志不要提交。完成后由玩家手动真实连接测试。

历史`build_map_test_exe_v1.py`依赖原版/v5及本地研究产物，不是现行公开重建入口。规则更新应记录来源与区域，先验证无关变化可复用、相关变化会拒绝，再构建、检查隐私并发布新标签，保留旧附件。
