# 工具与环境

普通玩家使用手动补丁无需Python；下面的开发工具按需要选用，不要求全部安装或购买。

|用途|工具与入口|说明|
|---|---|---|
|源码与差分|[Python](https://www.python.org/)|精确差分重建仅标准库；地图生成检查另装requirements-map.txt|
|图像与数据|[Pillow](https://pillow.readthedocs.io/)、[NumPy](https://numpy.org/)|处理alpha、坐标和预览，不能用亮度决定可走性|
|PSD读取|[psd-tools](https://github.com/psd-tools/psd-tools)|可选；不默认恢复已暂停的高清智能对象PSD流程|
|PE与反汇编|[pefile](https://github.com/erocarrera/pefile)、[Capstone](https://www.capstone-engine.org/)|查PE节和x86指令，避免错把VA当文件偏移|
|离线执行|[Unicorn](https://www.unicorn-engine.org/)|按夹具执行x86；不替代实际游戏操作|
|独立程序构建|[PyInstaller](https://pyinstaller.org/)|传送器构建源码在build_map_test_exe_v1.py；第三方通知见THIRD_PARTY.md；历史构建输入依赖见开发入口|
|GitHub维护|[Git](https://git-scm.com/)、[GitHub CLI](https://cli.github.com/)|开发者本机授权，不把凭据写进仓库|
|本机逆向分析|REA|可选，使用自己的安装与配置；项目不提供个人MCP配置或服务密钥；当前公开候选尚缺可核对的官方安装入口|

自研传送器为独立Windows程序，可支持核对过的Steam原版及补丁基线；未知改版会拒绝，不承诺所有第三方版本通用。使用自己的正常存档，通过Steam启动游戏后连接，测试时持续普通不遇敌，剧情强制战斗仍可能发生。

测试期间有存档守卫，结束后重新读正常档；返回起点只恢复位置，不恢复全部剧情状态。关闭工具停用测试，异常退出约3秒后租约失效。工具可能在旁边写配置、测试记录或错误日志，这些个人文件不随公开包分发。

当前公开包附组件许可与检查范围。传送器包含缩小的原生地图预览，用于定位测试；它们不是项目原创美术。源码在`补丁工作仓库/脚本`，不要发布私有运行记录或整套Python环境。

v0.3.1说明：可选传送器附件沿用v0.3.0，未知EXE会拒绝；本轮没有为其更新0.3.1身份/测试桥，不保证连接，请勿强行绕过校验。正常玩家不需要该工具。新增x86 C桥源码编译需Microsoft Visual C++ Build Tools的x86工具链。
